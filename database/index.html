Q&A

Q: Does this work with save files that have been converted using Transfarring?
A: As far as I can tell, yes.

Q: Can I edit Miller / Chico / Huey ...
A: Unique (UNQ) staff members have special game logic associated with them that makes editing some information impossible. For example, quotes for Unique characters and Hideo are set by the game, no matter what you set the quote as in the save file. If you want to edit some information for Unique characters, go to the Advanced tab, then check "Enable UNQ staff member editing".

Q: Why can't I edit a staff member's Gender / Location?
A: Again, because there is special game logic that means that if you change either of these, you'll have to change multiple other values as well. Staff location can easily be changed in-game; if a staff member is ill in the sickbay or stuck the brig, you can use the editor to clear all of their current statuses.
