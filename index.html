This tool is used for editing save files for Metal Gear Solid: Peace Walker for the Metal Gear Solid: Master Collection Vol. 2. This tool is only meant for PC: it will not work for console save files.

You can use this save editor to view an overview of your save file, edit Mother Base soldiers, edit R&D (Weapons/Items/Mechs/Other), edit Insignias, edit ZEKE, and track / edit different obtainable codenames. You'll need to upload your Peace Walker save file:

  • Save location: SteamLibrary\steamapps\common\MGS_PW\mgspw_savedata_win\[Your Steam ID]\ww
  • Find the save file you want: it will be in the format "STW000000xxxxx"
  • Make a backup of your save files before using the editor

Vicboss is an unofficial, fan-made save editor and is not affiliated with or endorsed by Konami. Editing save data may cause corruption or unexpected behaviour, so always create a backup before making changes. Use this tool at your own risk.
